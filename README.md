# TaskForgeAPI

A simple FastAPI backend project for task management (To-Do API), built to practice scalable backend architecture and RESTful API development.

## Features

- FastAPI
- CRUD Operations
- Modular Structure
- Database Integration 
- Pydantic Schemas

## Run

```bash
uvicorn app:app --reload
```

```bash
fastapi dev app.py
```
