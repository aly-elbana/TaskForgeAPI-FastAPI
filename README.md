# FastTaskAPI

A simple FastAPI backend project for task management, built to practice scalable backend architecture and RESTful API development.

## Features

- FastAPI
- CRUD Operations
- Modular Structure
- SQLite Database
- Pydantic Schemas

## Run

```bash
uvicorn app:app --reload
```

```bash
fastapi dev app.py
```
